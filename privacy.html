NOVA Hub Privacy Policy

Last updated: October 23, 2026

Who uses NOVA Hub

NOVA Hub is a personal assistant that Landon Talley built for himself. He is its only user. It runs on his own computer and is not available to the public.

What it accesses

With his permission, NOVA Hub reads Landon's own Gmail and Google Calendar so it can show him his email and schedule and help him draft messages and events. It only sends an email or changes his calendar when he approves that specific action.

Where the data stays

All data NOVA Hub reads from Google stays on Landon's computer. It is not uploaded to any server run by NOVA Hub, and there is no NOVA Hub server.

Sharing

No data is sold, shared, rented or used for advertising. No one other than Landon can see it.

Google API data

NOVA Hub's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
